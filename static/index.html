Audit coverage & safety

What this version actually measures.

CURRENT CAPABILITIES

PerceptaHeal checks document and element overflow, possible text clipping, overlap between controls/badges, and text contrast where a solid background color can be established. It records review notes for gradient/image contrast that is not measured, missing image alt text, small interactive targets and language hooks that are unavailable. External network resources are blocked during the server-side browser session. Repair CSS is applied only to a temporary Playwright preview; the target website's source files are never modified.
